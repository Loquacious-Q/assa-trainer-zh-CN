# 《刺客信条》系列 训练器合集（汉化版）

一个 exe 内含 9 款《刺客信条》训练器的中文汉化版，按游戏发行顺序排列，双击选单即可使用。
原版作者：hex（界面文字为二进制字符串级汉化，未改动程序代码段）。

## 下载

到 [Releases](../../releases) 里下载那个 `.exe`（约 71 MB），放到任意目录，双击，UAC 点"是"。

## 用法

先开游戏，再在合集里点对应那行的「启动」。需要管理员权限（训练器要读写游戏进程）。
多款可以同时开。

## 系统要求

- **64 位 Windows**：Windows 7 SP1 / 8 / 8.1 / 10 / 11 均可。
- **.NET Framework 4.x**：Win8 及以后系统自带；Win7 若未安装需先装一个。
- 32 位 Windows 不支持（其中 5 款训练器本身是 64 位程序）。
